# ➕ 문자열 덧셈 계산기

## 📝 기능 목록

#### 1. 애플리케이션을 실행하면, '덧셈할 문자열을 입력해 주세요.' 안내 문구를 출력한다.

#### 2. 사용자로부터 입력을 받는다.

- 입력값이 비어 있는 경우, "0"으로 처리한다.

#### 3. 입력값이 "//"로 시작하고 "\n"을 포함하는 경우 커스텀 구분자를 추출한다.

- 입력값이 "//"로 시작하지만 "\n"을 포함하지 않는 경우, `IllegalArgumentException`을 발생시킨다.
- 추출한 커스텀 구분자가 한 글자가 아닌 경우, `IllegalArgumentException`을 발생시킨다.

#### 4. 구분자(기본 구분자, 커스텀 구분자)로 입력값을 분리한다.

#### 5. 분리한 문자열 리스트를 숫자 리스트로 변환한다.

- 문자열을 숫자로 변환할 수 없는 경우, `IllegalArgumentException`을 발생시킨다.

#### 6. 숫자 리스트의 합을 계산한다.

#### 7. 덧셈 결과를 출력한다.

## 💡설계

#### Model

- 입력 문자열을 검증한다.
    - 비어 있는 경우, 예외를 발생시킨다.
    - 커스텀 구분자를 추출하고, 유효성을 검사한다.
    - 문자열 리스트를 숫자 리스트로 변환한다. 숫자 변환 실패 시 예외를 발생시킨다.
- 숫자 리스트의 합을 계산한다.
- 덧셈 결과를 반환한다.

#### View

- 문자열 덧셈 계산기 안내 문구를 출력한다.
- 사용자로부터 입력을 받는다.
- 계산 결과를 출력한다.

#### Controller

- View로부터 입력값을 전달 받는다.
- Model에 계산을 요청한다.
- Model에서 반환된 결과를 View에 전달한다.
