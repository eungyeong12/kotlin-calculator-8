# 문자열 덧셈 계산기

## 기능 목록

### 1. 구분자와 양수로 구성된 문자열을 입력받는다.

### 2. 입력 문자열 앞부분이 "//"로 시작하고 "//"와 "\n" 사이에 하나의 문자가 위치할 경우, 해당 문자를 구분자 리스트에 추가한다.

- 구분자에는 기본적으로 쉼표(,)와 콜론(:)이 존재한다.

### 3. 구분자 리스트의 구분자들을 기준으로 문자열을 분리한 후, 숫자로 변환한다.

- 문자열을 숫자로 변환하는 데 실패할 경우, IllegalArgumentException을 발생시킨다.
- 변환된 숫자가 음수인 경우, IllegalArgumentException을 발생시킨다.

### 4. 숫자 리스트의 합을 구한 후, 결과를 출력한다.
